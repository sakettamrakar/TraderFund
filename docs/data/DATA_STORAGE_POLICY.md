# Data Storage Policy

## 1. What data is generated?
Three types of data are generated by the system:
- **Raw Data**: Direct API output (JSONL) from Angel One.
- **Processed Data**: Cleaned, deduplicated, and formatted market storage (Parquet).
- **Observation Data**: Daily logs and clinical review CSVs used for manual verification.

## 2. Where does it live?
All generated files are stored in the root directory under:
- data/raw/: Original API responses.
- data/processed/: Standardized market candles.
- observations/: Daily run logs and signal reviews.

## 3. What is NOT committed?
Runtime market data is not committed to GitHub.

- `data/raw/` and `data/processed/` are ignored runtime outputs.
- Large generated raw file types like `*.jsonl`, `*.parquet`, `*.csv`, and `*.feather` are blocked globally.
- Exception: `data/fixtures/` contains tiny canonical test fixtures used by fixture-mode validation and is intentionally trackable.

## 4. How to clean / reset data?
If you want to start from a "clean slate" (e.g., to force a full re-process), you can safely delete the contents of these folders.

# Command (PowerShell):
# Deletes all raw and processed market data
# Remove-Item -Recurse -Force data/*

# Deletes observation execution logs (keeps notes)
# Remove-Item -Recurse -Force observations/daily_logs/*
# Remove-Item -Recurse -Force observations/signal_reviews/*

Warning: Deleting files in data/raw/ is permanent. If deleted, you will need to re-fetch that historical data from the API.
